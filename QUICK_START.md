# 🚀 Quick Start Guide - StreamWave Music Platform

## За 5 хвилин до запуску!

### Крок 1: Встановлення (1 хвилина)

```bash
# Встановіть залежності фронтенду
npm install

# Встановіть залежності бекенду
cd backend
npm install
cd ..
```

### Крок 2: Запуск (2 хвилини)

**Відкрийте ДВА терміналі:**

**Terminal #1 - Frontend:**
```bash
npm start
```
✅ Автоматично відкриє http://localhost:3000

**Terminal #2 - Backend:**
```bash
cd backend
npm start
```
✅ Запущено на http://localhost:5000

### Крок 3: Користуйтеся! (2 хвилини)

1. 🎵 **Клацайте на трек** → грає музика
2. ❤️ **Натисніть серце** → додає в улюблені
3. 🔍 **Пошук** → знаходить треки
4. 📻 **Жанри** → фільтрує музику
5. ⏯️ **Плеєр** → всі контролі внизу

## 📱 Функціональність

| Функція | Як користуватися |
|---------|-----------------|
| **Прослуховування** | Клацніть на трек |
| **Улюблені** | Серце (❤️) в правому куті картки |
| **Пошук** | Введіть у поле пошуку вгорі |
| **Фільтрація** | Виберіть жанр під поле пошуку |
| **Play/Pause** | Велика кнопка внизу екрана |
| **Наступний/Попередній** | Стрілки (← →) внизу |
| **Гучність** | Слайдер праворуч |
| **Перемотування** | Клацніть на прогрес-бар |
| **Shuffle** | Хаотична іконка внизу |
| **Repeat** | Значок повтору внизу |

## 🔴 Если щось не працює

### API не відповідає (Error на фронтенді)
```bash
# Перевірте, чи запущений бекенд
curl http://localhost:5000/api/health

# Якщо не відповідає, перезавантажте
pkill -f "node server.js"
cd backend && npm start
```

### Музика не грає
```bash
# Перевірте браузер консоль (F12)
# Может браузер блокує auto-play (дозвольте звук)
```

### Порт 3000 уже в використанні
```bash
# Знайдіть процес
lsof -i :3000

# Вбийте його
kill -9 [PID]

# Або змініть порт
PORT=3001 npm start
```

### Порт 5000 уже в використанні
```bash
# Змініть PORT у backend/server.js
```

## 💾 Дані

### Де зберігаються улюблені і історія?

**localStorage (браузер):**
- Автоматично зберігаються локально
- Залишаються після перезавантаження сторінки
- Легко видалити через DevTools (F12 → Storage)

**REST API (опціонально):**
- Також можна синхронізувати з бекендом
- Для хмарного збереження (майбутнє)

## 🎯 Примеры запитів до API

```bash
# Отримати всі треки
curl http://localhost:5000/api/tracks

# Пошук треку "sunny"
curl http://localhost:5000/api/tracks/search/sunny

# Додати до улюблених (замініть user_id та track_id)
curl -X POST http://localhost:5000/api/favorites/user_123/1

# Створити плейліст
curl -X POST http://localhost:5000/api/playlists/user_123 \
  -H "Content-Type: application/json" \
  -d '{"name": "Мій плейліст"}'
```

## ⚠️ Важливо

1. **Два термінали потрібні!** - Фронтенд (3000) + Бекенд (5000)
2. **Дайте часу на завантаження** - Перший запуск займає ~ 30 сек
3. **Дозвольте звук у браузері** - Деякі браузери блокують auto-play
4. **Використовуйте сучасний браузер** - Chrome, Firefox, Safari, Edge
